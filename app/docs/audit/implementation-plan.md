Запрос: аудит приложения, улучшение дизайна с использованием дизайн-скиллов, новый адрес и фирменная иконка в поиске. Пользователь поручил приступить; решения принимаются в рамках существующей идентичности.

## Направление
Сохраняем React + Tailwind + FastAPI, синий #074089, существующий логотип, русский и английский языки. Улучшаем существующий сайт: спокойная медицинская подача, понятная иерархия, адаптивная шапка и доступные элементы. Полная смена бренда или платформы не нужна.

## План
- Зафиксировать исходные SHA256: baseline-hashes.json. Git в переданной папке отсутствует.
- Проверить публичные страницы, корзину, API, админку, SEO и сборку; описать подтверждённые риски отдельно от непроверенных.

- Закрыть неавторизованное чтение заявки; экранировать пользовательские данные в Telegram и JSON-LD; проверить регрессии без отправки настоящих заявок.

## Критерии
Доступность favicon без backend; единый новый адрес; отсутствие горизонтальной прокрутки на 360/768/1440 px; работа поиска, языка, навигации и корзины; приватные заявки требуют токен; безопасная сериализация JSON-LD. Отсутствие рабочей БД не заменяется вымышленными результатами. Публикация и переиндексация не считаются выполненными без подтверждения.
