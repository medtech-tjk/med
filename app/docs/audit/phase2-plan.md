# Согласованный этап 2: интерфейс и взаимодействия

Основание: пользователь согласовал шапку, каталог, карточки и микроанимации; дополнительно поручил перепроверить цвета, сетку шапки/подвала и админку/API. Сравнение не требуется. Объявления о переезде запрещены предыдущим уточнением.

Дизайн: сохраняем фирменный синий #074089. Убираем оставшиеся мятные токены, вводим единые фон, обводки, текст, цвета состояний. Общая сетка до 1320 px, одинаковые поля у шапки, содержимого и подвала. Карточки с ровной областью фото, брендом, названием и выровненными действиями; минимум постоянного движения. CSS transitions 120–220 ms для реакций и состояний, reduced-motion. Без дополнительной библиотеки анимации.

Порядок реализации:
1. Снимок входных файлов и общий набор цветов/сетки.
2. Перестроить шапку и подвал, сделать предсказуемые навигацию и поиск.
3. Доработать карточки каталога/товаров и страницу товара: визуальная иерархия, фото, действия и вкладки.
4. Устранить обнаруженные проблемы фильтрации/загрузки и API админки; протестировать просроченный токен и ошибки сервера без настоящих записей.
5. Проверить публичные страницы и админку на узких/широких экранах, контраст основных пар, взаимодействия и reduced-motion. Сборка, unit/API тесты, отчёт.

Границы: без смены бренда, сравнения, настоящих CRUD-операций production и публикации. Интеграционные проверки — изолированные фикстуры и поддельная БД. Недоступные live-проверки фиксируются отдельно.
