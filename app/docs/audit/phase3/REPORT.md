# Этап 3: фильтры и удаление подсказок

Проверено локально 29 октября 2026. По вопросу владельца актуализирован раздел «Осталось / порядок дальнейшей работы» в `../AUDIT.md`: пункты имеют статусы «Открыт» или «Частично», а не выданы за завершённые.

## Что изменено

| До | После | Результат |
|---|---|---|
| Закрытые select с обрезанными длинными значениями | Общий FilterOptions с переносом полного текста | Названия брендов и характеристик читаются целиком |
| Вложенные прокрутки в списках | Первые 6 вариантов, раскрытие оставшихся и поиск для больших списков | Одна прокрутка страницы, все варианты достижимы |
| На планшете кнопка фильтров скрывалась раньше панели | Единый breakpoint 1024 px | Панель можно открыть на 768 px |
| Закреплённые длинные панели могли накладываться на шапку | Панели в обычном потоке, отступы прокрутки для фокуса | Нижние действия не зажаты внутри панели |
| Выбранный вариант пропадал после снятия отметки в свёрнутом списке | Недавно показанный вариант остаётся на месте | Сохраняется фокус и стабильное положение списка |
| Выбор бренда сужал сам список доступных брендов | Фильтрация по исходному набору товаров без перезапроса одного бренда | Остальные бренды остаются доступны |
| Товар без выбранной характеристики мог остаться в выдаче | Отсутствующее значение исключается; сравнение точное с нормализацией регистра | Фильтр соответствует выбранному условию |
| При смене языка мог вернуться старый набор характеристик | Отмена предыдущего запроса и сброс старых выбранных характеристик | Не остаются невидимые ограничения от прошлого языка |
| Синие панели «Как это работает», «Структура каталога», «Информация» | Удалены из настроек, категорий и избранных товаров | Админка без обучающих простыней |
| Избыточные инструкции в форме товара и пустых списках | Удалены повторяющиеся подсказки | Сохранены названия полей, ошибки и краткие ограничения форматов файлов |

Сравнение, объявления о переезде и новые рекламные блоки не добавлялись.

## Проверки

- `build-final.txt` — production-сборка.
- `frontend-tests.txt` — 11 unit-тестов, включая отсутствие товаров без нужной характеристики, точное совпадение бренда и сохранение фокуса при снятии отметки.
- `browser-results.json` — 16 сочетаний маршрута/ширины: поиск, категория, подкатегория, третий уровень × 360/768/1024/1440 px. Фикстура содержит 12 длинных брендов, 12 длинных характеристик с неразрывным словом и много соседних категорий. Проверены раскрытие, поиск, полный текст, выбор бренда, сброс, доступность нижних действий и отсутствие горизонтального переполнения.
- Дополнительно проверены 4 административные страницы на отсутствие удалённых подсказок; снимок `settings-without-hints.png`.
- Повторный регрессионный прогон этапа 2 прошёл: ещё 39 проверок маршрутов/размеров, включая создание/редактирование тестового товара, загрузку, статус заявки, курс и истёкшую сессию. Все запросы перехвачены, реальных записей нет.
- Повторный npm audit по текущему lockfile: **36 предупреждений, включая 14 high; critical — 0**. Отчёт `../npm-current.json`. Эти пункты остаются открытыми.

Все браузерные запросы API перехвачены тестовой фикстурой. Рабочая БД, реальные записи и публикация не затрагивались. Проверка фильтров относится к отображению и корректности на полученном наборе: ограничение объёма набора API требует отдельной серверной пагинации.
