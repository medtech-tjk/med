# Инструкция по запуску проекта Tib Technology

## Быстрый старт

### 1. Запуск Backend (в первом окне терминала)

```powershell
cd c:\Users\Alijon\Documents\app\backend
python -m uvicorn server:app --reload --host 0.0.0.0 --port 8000
```

Backend запустится на: http://localhost:8000

### 2. Запуск Frontend (во втором окне терминала)

```powershell
cd c:\Users\Alijon\Documents\app\frontend
npm start
```

Frontend откроется автоматически на: http://localhost:3000

> **Примечание**: Если команда `npm start` не работает из-за ограничений PowerShell, запустите терминал от имени администратора или используйте cmd.exe

## Что проверить после запуска

### На главной странице
1. Проверьте работу слайдера (если есть слайды в админке)
2. Проверьте отображение товаров
3. Кликните на "О компании" в футере - должна открыться новая страница
4. Кликните на "Наши услуги" в футере - должна открыться новая страница

### Страница "О нас" (http://localhost:3000/about)
1. Проверьте отображение истории компании (2007, 2018)
2. Проверьте карточки клиентов
3. Проверьте карточки поставщиков

### Страница "Услуги" (http://localhost:3000/services)
1. Проверьте 6 категорий услуг
2. Проверьте статистику компании внизу

### Карточки товаров
1. Цена должна быть чёрная, не жирная
2. Индикатор "В наличии" должен иметь зелёный фон с анимацией

### Админ-панель (http://localhost:3000/admin)

**Логин**: введите admin token из файла `backend/admin_token.txt`

После входа проверьте:

1. **Товары → Новый товар**:
   - Заполните название, категорию, цену в TJS
   - **Добавьте цену в USD** (новое поле!)
   - Сохраните товар

2. **Слайдер**:
   - Попробуйте добавить новый слайд
   - Загрузите изображение
   - Проверьте что слайд появился на главной

3. Переключите валюту на сайте (TJS ↔ USD):
   - Если вы указали цену в USD в товаре, она будет использоваться
   - Если не указали, цена будет конвертироваться по курсу

## Если возникли проблемы

### Frontend не запускается
```powershell
# Попробуйте переустановить зависимости
cd c:\Users\Alijon\Documents\app\frontend
rm -r node_modules
npm install
npm start
```

### Backend не запускается
```powershell
# Проверьте что установлены зависимости
cd c:\Users\Alijon\Documents\app\backend
pip install -r requirements.txt
```

### Проблемы с MongoDB
Убедитесь что MongoDB запущен локально или проверьте файл `.env` в папке backend
